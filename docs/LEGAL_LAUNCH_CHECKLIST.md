# Shin's House 법적 고지 상용화 체크리스트

> 운영 준비를 위한 기술/콘텐츠 체크리스트입니다. 실제 영업형태와 상품에 따라 전문가 검토가 추가로 필요할 수 있습니다.

기준 확인일: 2026-09-21

## 1. 사이버몰/통신판매 신원정보
주문을 활성화하기 전에 실제 값으로 확인합니다.
- [ ] 상호
- [ ] 대표자 성명
- [ ] 영업소 및 소비자 불만처리 주소
- [ ] 전화번호
- [ ] 전자우편주소
- [ ] 사업자등록번호
- [ ] 통신판매업 신고번호 및 신고 확인정보
- [ ] 이용약관 접근 링크

참고: 전자상거래 등에서의 소비자보호에 관한 법률 제10조·제13조.

## 2. 주문 전 거래조건
- [ ] 상품명/구성/수량/가격
- [ ] 배송비 및 추가비용
- [ ] 결제수단과 입금 확인 절차
- [ ] 공급/배송 시기
- [ ] 취소·교환·반품·환불 조건과 비용 부담
- [ ] 고객이 주문내용을 최종 확인·수정할 수 있는 단계

## 3. 청약철회
기본 안내는 법 제17조를 기준으로 구성합니다.
- [ ] 원칙적 7일 기준 안내
- [ ] 소비자 책임 훼손, 사용/소비에 따른 가치 감소, 시간 경과로 재판매 곤란 등 법정 제한사유 안내
- [ ] 제한사유가 있다고 모든 원두/식품을 일률적으로 환불 불가 처리하지 않음
- [ ] 표시·광고 또는 계약과 다르게 공급된 경우 별도 법정 기준 안내

## 4. 거래기록 보존
전자상거래법 시행령 제6조 기준으로 시스템 보존정책을 설정합니다.
- [ ] 표시·광고 기록: 6개월
- [ ] 계약/청약철회 기록: 5년
- [ ] 대금결제/재화 공급 기록: 5년
- [ ] 소비자 불만/분쟁처리 기록: 3년
- [ ] 고객이 주문기록을 조회하거나 요청할 수 있는 방법 제공

- [ ] 보유기간 및 법정 보존근거
- [ ] 파기절차/방법

- [ ] 고객 권리 행사방법
- [ ] 실제 배송사/호스팅/DB 등 수탁자와 처리업무 확정
- [ ] 필요한 경우 국외 처리/이전 관련 고지 검토
- [ ] 주문 시 동의한 정책 버전과 시각을 DB에 저장

## 6. 사이트 적용
- `/legal/terms`
- `/legal/privacy`
- `/legal/refund`

`LEGAL_APPROVED=false` 상태에서는 정책 페이지가 검토용 초안임을 표시하고 검색엔진 색인을 막습니다.
실제 등록정보, 처리위탁, 배송/환불 운영정책 검토 후에만 `LEGAL_APPROVED=true`로 변경합니다.
