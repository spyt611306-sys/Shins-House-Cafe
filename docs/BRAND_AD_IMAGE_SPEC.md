# Shin's House 광고 이미지 제작 기준

## 공식 브랜드 자산
- 공식 마스코트: 사용자가 제공한 커피잔을 든 강아지 캐릭터
- 공식 워드마크: `Shin's House`
- 홈페이지 상단/광고/패키지에서 임의의 집 아이콘만 단독 로고처럼 사용하지 않는다.
- 생성 이미지 속 로고 글자는 AI가 임의로 생성하지 않고, 후편집 시 공식 자산을 별도로 합성하는 방식을 우선한다.

## 인물 광고 다양성 규칙
동일 인물·동일 미소·동일 정면 포즈를 반복하지 않는다. 한 캠페인 내에서 아래 장면을 섞는다.
1. 로스터 앞에서 원두 향을 확인하는 집중 표정
2. 핸드드립 중 주전자에 시선을 둔 측면 동작
3. 에스프레소 머신 스팀 작업 중 자연스러운 작업 표정
4. 커피 농장에서 체리를 살피는 야외 장면
5. 고객에게 커피를 건네며 밝게 웃는 장면
6. 테이블에서 원두 노트를 기록하는 차분한 장면
7. 선물세트를 포장하는 손 동작 중심 장면
8. 아이스커피를 들고 이동하는 밝은 여름 장면
9. 창가에서 커피를 마시는 휴식 장면
10. 원두/드리퍼/패키지가 중심인 인물 없는 제품 광고

## 해부학/AI 오류 금지
- 사람 1명당 팔 2개, 손 2개, 각 손 손가락 구조 정상 여부 확인
- 손이 컵/포트/포장재를 관통하거나 중복되지 않도록 확인
- 얼굴 비대칭, 치아/눈 중복, 귀/머리카락 융합 금지
- 배경 인물의 손·얼굴도 최소한의 정상 형태 유지
- 제품 패키지에 무작위 영문/가짜 로고를 생성하지 않는다.

## 화면별 권장 이미지
- Hero: 16:9, 인물 또는 로스터리의 강한 대표 컷
- Brand story: 3:2, 농장/로스팅/작업 과정
- Coffee finder: 4:3, 테이스팅 플라이트 또는 향미 비교
- Product: 1:1 또는 4:5, 패키지 중심
- Gift: 4:3, 포장/리본/선물 구성
- Subscription: 4:3, 월간 커피 박스/배송 구성
- Mobile banner: 4:5 또는 9:16 별도 크롭

## 품질 기준
- 원본 생성 목표: 2048px 이상
- 웹 배포: WebP/AVIF, 사용 영역별 srcset
- Hero는 LCP 우선순위 적용, 하단 이미지는 lazy load
- 색감은 크림/월넛/커피브라운/따뜻한 자연광을 유지하되 모든 컷의 조명과 배경을 동일하게 만들지 않는다.
